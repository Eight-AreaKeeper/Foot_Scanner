# Foot Scanner

用手机拍一张照片、配一张 A4 纸，测量脚长、跖围宽、脚跟宽，并给出参考鞋码。这是整个球鞋定制项目的第一阶段（M1）算法原型，验证可行后移植到 iOS App。完整技术方案见 [docs/tech-design.md](docs/tech-design.md)。

## 怎么拍

**自由模式（默认）**
1. A4 纸平铺在**深色、硬质**的地面上（别用浅色瓷砖或地毯）。
2. 赤脚或穿浅色薄袜，站在纸中间，两脚均匀承重，裤腿卷到脚踝以上。
3. 请别人在**脚踝正上方**往下拍，手机离地 50 cm 以上；纸的四个角都要在画面里。

**靠墙模式（`--mode wall`）**：纸的短边贴墙，脚跟贴墙站在纸上。脚跟位置就是纸边，不受小腿遮挡影响，脚长最稳。

光线均匀、避免强烈阴影。

## 运行

```bash
pip install -e ".[dev]"
python -m foot_scanner photo.jpg --debug out.png
python -m foot_scanner photo.jpg --mode wall
```

## 算法流程

1. **找纸**（`paper.py`）：画面中最大的亮、低饱和区域，取凸包拟合四边形，再用边线拟合求亚像素角点，得到纸面毫米坐标到图像的单应性矩阵。脚踩在纸中间不影响凸包。
2. **相机位姿**（`camera.py`）：由单应性矩阵恢复相机在纸面坐标系中的位置。焦距优先读 EXIF 的 35 mm 等效焦距，没有就从单应性估计，再不行用 iPhone 主摄默认值。
3. **分割脚**（`segment.py`）：把纸校正成每毫米 4 像素的俯视图，用纸边一圈拟合光照，按"比纸暗多少 + 偏离纸色多少"打分并自动取阈值。
4. **视差校正**：脚的轮廓不在纸平面上（脚跟最后点离地约 25 mm，前掌约 10–12 mm），斜着拍时会被投影"推远"。已知相机位置后，把每个轮廓点沿视线拉回到它的高度。相机在脚正上方 50 cm 时，不校正脚长会偏大 9 mm 左右。
5. **测量**（`measure.py`）：主成分分析求脚轴，宽的一头是前掌；脚长为沿脚轴的最大长度，跖围宽为脚长 55%–85% 区间内的最大宽度，脚跟宽取距脚跟 16% 处。
6. **鞋码**（`sizing.py`）：厘米码向上取半码，再按常见运动鞋尺码表换算美码、欧码。

## 测试

```bash
pytest -q
```

测试用 `synth.py` 按针孔相机模型渲染"脚踩在 A4 纸上"的照片，脚轮廓各点带真实高度。在不同相机位置、角度、脚型下，脚长、跖围宽、脚跟宽与真值的误差都在 1 mm 以内（未给焦距时 1.5 mm）。

## 已知局限（下一步要解决的）

- **只在合成图上验证过**。合成图没有阴影、皮肤纹理、袜子、小腿和裤腿，真实照片的精度要用实拍加卷尺 / 量脚器的真值来测。
- **轮廓高度是经验值**（`DEFAULT_EDGE_HEIGHT_PROFILE`）。这是视差校正里最大的不确定来源，需要用真值数据标定。
- **阴影**：浅色阴影一般低于阈值，深阴影可能被并进脚里。
- **小腿遮挡**：自由模式下相机越靠近脚尖，小腿越会在画面里盖住脚跟后方，会给出提示；靠墙模式不受影响。
- **脚长超过约 290 mm** 时 A4 放不下，可用 `--paper a3`。
- 只有俯视数据，没有脚背高度、足弓、围度，这些要等侧视图或 3D 扫描（M2）。
